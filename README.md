# AZ-900 Smart Quiz (Unofficial)

> **Unofficial study tool.** This project is not affiliated with, endorsed by, or sponsored by Microsoft.
> All questions are original and are based on the public AZ-900 skills outline on Microsoft Learn.
> No real exam questions are used.

Built for the **#1MillionDevs Vibe Coding Hackathon: AZ-900 Exam Prep Edition**
(challenge: *Practice & Assessment, Smart Quiz Builder*).

## The problem

Many learners practise with questions but do not understand why an answer is right or wrong.

## The idea

A quiz app that gives **instant feedback and a clear explanation for every answer**, organised by
the topics of the AZ-900 skills outline.
